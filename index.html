Google Drive eşleşmesi

Bağlı değil
Veriler Drive’da yalnızca bu uygulamanın görebildiği gizli bir klasöre yazılır. Telefonda ve bilgisayarda aynı Google hesabıyla bağlan; kayıtlar birleşir. Yedek al / Yedekten yükle ayrıca çalışır.
Client ID nasıl alınır?
1) console.cloud.google.com → proje seç → “API’ler ve Hizmetler” → Kitaplık → Google Drive API → Etkinleştir.
2) “OAuth izin ekranı” → Uygulama durumu Yayında olsun (Test modunda giriş 7 günde düşer). Kapsam olarak yalnızca drive.appdata yeterli.
3) “Kimlik bilgileri” → Kimlik bilgisi oluştur → OAuth istemci kimliği → Web uygulaması. “Yetkili JavaScript kaynakları”na https://egeteknoloji.github.io ekle (sonunda / olmasın).
4) Oluşan Client ID’yi (…apps.googleusercontent.com) yukarıya yapıştır. Başına “http” gibi bir ek gelmediğinden emin ol.
